How it works — and its limits

Factors. 12 macro drivers, each z-scored on a 252-day rolling window and oriented bullish-positive, so the model reacts to unusual moves, not levels. Weights come from each factor's univariate correlation with forward gold returns (floored at zero), then a logistic calibration maps the composite to a probability. Every weight is inspectable — no black boxes.
Signal. LONG at P≥0.60, SHORT at P≤0.40, otherwise FLAT. Refit on all history each run; the JSON the EA reads carries per-factor contributions, z-scores, weights and calibration.
The bot. The MT5 Expert Advisor reads the signal file every 60s, trades XAUUSD with 1% risk, $30 SL / $60 TP, and does nothing on a stale (>36h) or missing signal — by design. The EA file is carefully written but uncompiled: compile in MetaEditor (F7) and forward-test on demo before any live use.
Honest limits. Walk-forward 2019–2026: the signal strategy made 2.3%/yr at 0.33 Sharpe vs 15.8%/1.04 buy-and-hold — this is a defensive regime filter, not a money printer. It shines by sidestepping drawdowns (2021, 2022), not by manufacturing return in a one-way bull market. Central-bank demand is a manual quarterly input. Fed expectations are proxied via yields, not futures.
