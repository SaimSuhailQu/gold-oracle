Honest limits

  • Does not beat buy-and-hold in a bull market. 14.9% strategy CAGR vs 15.8% buy-and-hold (2019–2026, walk-forward). Use as a defensive regime filter, not a money printer.
  • Backtest covers the base 12-factor model only — the ensemble, sentiment, microstructure and critic layers are too new to have walk-forward history. Their edge is unproven.
  • Factors are slow-moving; the model times 20-day swings, not intraday moves.
  • Sentiment is a word-count lexicon on free headlines, not an LLM — but it's now calibrated as a rolling 30-day z-score, so only genuine anomalies nudge the model. FinBERT/LLM backend is a documented drop-in (narrative.set_backend()).
  • YouTube memory only matters if channels are actually tracked; otherwise it contributes nothing.
  • VWAP/profile use real 1-minute data (Dukascopy XAU/USD ticks, Kraken PAXG fallback) when the feed is reachable — check the data source badge. If both fail, it falls back to the old daily-close synthesis, which is clearly labeled.
  • Central-bank demand is a manual quarterly input, not a live feed.
  • The MQL5 EA was carefully written but never compiled — compile in MetaEditor (F7) and forward-test on demo before anything touches a live Exness account.
